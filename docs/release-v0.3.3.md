# v0.3.3：分钟探测超时率与链路异常提示

本次更新覆盖 Windows GUI 及 Windows/Linux CLI。协议仍为 v9，兼容 v0.3.1/v0.3.2 客户端和服务端；现有 v9 服务端无需升级。

## 如何阅读链路质量

每位对端的 TCP 流量路径、UDP/其它流量路径分别每秒探测一次。界面每秒刷新最近 60 秒的结果，探测发出后达到 10 秒没有及时回应计为超时。

`探测超时率 = 超时数 /（及时回复数 + 超时数）`。尚在等待的探测不进入分母；本地发送失败单列。少于 5 个已判定样本显示“采样中”，详情和 CLI `peers` 提供样本明细。

这是端到端探测的超时率，经过 KCP、FEC、TCP 补回的丢包不会计入，不能作为底层 UDP 原始丢包率。它与 RTT 一起帮助定位当前传输路径是否可用。

## 提示与单人房间

- 只探测其他成员，本机质量显示“—”。单人房间显示暂无对端、无法评估，不计算超时率或触发成员异常提示。
- 路径尚未建立时显示连接中。已建立且成功提交探测的路径连续 10 秒没有及时回应，才显示异常。
- 实际传输为 Raw UDP/KCP 时提示 UDP 路径可能受限；实际为 TCP Relay 时提示通用链路异常。流量类型与底层传输方式不同：TCP 游戏流量也可能经过 Raw UDP。
- UDP 提示建议检查服务端 UDP 端口、防火墙和对端状态，必要时将房间两项策略都设为 TCP Relay。超时并不能证明一定被防火墙阻断。
- 同一异常只记录一次告警；连续两次及时回应后清除并记录恢复。成员离开时清除其提示，最后一位对端离开后恢复单人状态。
- 提示不自动修改防火墙、切换策略或退出房间。Windows 原有 DPI/UAC 和网卡就绪检查保留。

## 构建与验证边界

Windows GUI 使用 Qt 5.9.9 / MSVC 2015 x64，发布完整运行库与官方 x64 Wintun。所有发布资产及校验和对应同一提交。

本次回归使用共享状态机测试、生产 GUI/CLI 探测回显、用户态延迟/丢包/阻断仿真，以及无 TUN 界面夹具。无需管理员凭据，不创建虚拟网卡、不改路由或防火墙。模拟测试不等于真实跨网络 Wintun 或游戏互通验收。
